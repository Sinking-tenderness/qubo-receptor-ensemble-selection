# 量子 QUBO 受体构象组合项目交接（Stage19-Stage112）

## 1. 一句话现状

本项目已经建立了一条可复现的“受体构象池 -> Uni-Dock 虚拟筛选 -> 嵌套验证 -> QUBO/经典组合选择 -> 硬件可行性审计”流程；证据表明构象互补性真实存在但高度依赖靶点，当前没有跨蛋白稳定优于强经典基线的 QUBO，也不能主张量子优势。

下一步不是继续调旧 QUBO 权重或购买量子硬件，而是对已纠正身份的凝血酶（DUD-E `THRB`，F2/P00734）从一份全新预注册开始，验证“共晶接触状态”能否在对接前识别真正值得做多构象组合的靶点。

## 2. 项目问题与固定评价口径

### 原始问题

从一个蛋白的多个可用受体构象中，选择少数构象组成筛选集，希望尽早把活性分子排到诱饵之前。组合选择可写为二元变量 $x_i \in \{0,1\}$ 的 QUBO/CQM 问题；但“能写成 QUBO”不是科学价值，必须同时满足外部筛选价值和经典求解困难。

### 核心评价规范

- 主指标：`BEDROC20`，即 BEDROC 的 $\alpha=20$；数值越高表示活性分子越早出现。
- 对接引擎：Uni-Dock `v1.1.3`；关键生产矩阵使用 3 个独立随机种子。
- 选择/评估：内层训练选择，外层留出数据评估；不得用外层 BEDROC 回调 QUBO 权重或 $k$。
- 强对照：单受体、线性 Top-$k$、直接贪心、穷举/MILP（可精确问题）、RF、XGBoost、GBT、LR、共识排序等。
- 科学成功：未参与选择的数据上，超过预先指定的经典基线；仅“对接跑通”或“量子硬件有返回”不算成功。

## 4. 已经可以说、不能说什么

### 可以说

1. 多构象筛选不是普适增益，而是靶点条件化问题。
2. FA10 是稳定双构象正例，EGFR 是明确单构象反例；两者使用同一评估框架，构成重要正反对照。
3. 简单几何距离或“选最不同构象”不足以解释功能互补；共晶接触状态是值得验证的筛选前信息。
4. QUBO 对预算、冗余、覆盖等组合约束有自然表达能力，并在 Stage68 展示了受约束去冗余的可用性。
5. 已确认的主要瓶颈是目标函数对留出筛选价值的估计偏差，而非经典算法没有找到好解。

### 不能说

1. 不能说 QUBO 普遍超过贪心、单受体、RF、XGBoost 或其他经典基线。
2. 不能说 QUBO 已在新靶点上独立验证成功；FA10 与 EGFR 是开发阶段正反例。
3. 不能说存在量子速度、质量或“量子优势”。
4. 不能把 Dirac-3 的局部修补成功写成核心创新；相同实例对经典局部搜索也很简单。
5. 不能把 Stage110 的旧 THRB “19 个结构”当成凝血酶证据。

## 5. 当前可投稿的科学叙事

更稳妥的论文命题不是“量子 QUBO 战胜经典虚拟筛选”，而是：

> 受体构象组合的功能互补高度靶点依赖；结构多样性本身不足以预测早期富集增益。通过严格的嵌套验证、正反靶点对照和可审计的 QUBO 诊断，可以识别何时多构象组合值得采用，何时应停在单构象。

可作为方法学贡献的内容：

- 多靶点、三种子、嵌套外层评价的受体组合评估框架；
- 与强经典求解器的精确对照，明确区分“建模价值”和“量子求解价值”；
- FA10/EGFR 正反对照及 Stage106 的接触状态覆盖假设；
- 质量-冗余折中的 QUBO/CQM 形式与其明确适用边界；
- 负结果本身：哪些看似合理的 QUBO、结构多样性和硬件路线会失败，以及为什么失败。

## 6. 下一位同学的严格执行顺序

### A. 先做凝血酶的独立预注册，不要先下载或对接

新阶段须单独冻结以下内容：

1. 靶点身份：DUD-E `THRB` = thrombin/F2，UniProt `P00734`，参考 PDB `1YPE`。
2. 参考结构门：必须核验野生型、正确主链、非共价配体、可解释口袋；不得沿用 P10828 的任何筛查计数。
3. 结构池门：仍用现有阈值，即至少 32 个元数据合格候选，且在坐标与重对接门之后至少保留 16 个受体。
4. 功能门：先固定单受体、线性 Top-$k$、直接贪心、强经典优化和精确/MILP 对照；必须预先写明新靶点上成功的 BEDROC20 判据。
5. 信息边界：在结构池和预注册通过前，不读取新靶点配体标签、对接矩阵、确认集或测试集结果。

### B. 只验证一个新的、事先冻结的机制假设

推荐假设是：共晶配体的口袋接触状态覆盖，能否在对接前帮助判断多构象组合是否值得尝试。

- 不从 FA10/EGFR 回调 Jaccard 阈值或 QUBO 系数。
- 先输出接触状态描述符和预先声明的决策规则；再产生 Uni-Dock 矩阵。
- 如果凝血酶不通过结构门、或外层功能门未通过，应如实停止这条机制路线，而不是更换目标函数救结果。

### C. 量子硬件重新启动的双门槛

只有以下两项同时满足才重新申请 QCI/D-Wave/门模型硬件：

1. **生物学价值门**：冻结的组合规则在未参与选择的数据上优于指定强经典基线，最好有多蛋白复现或一个真正未接触靶点的确认。
2. **求解困难门**：QUBO 全局最优与贪心/一步交换不同，且这个差异有外部 BEDROC20 价值；小规模有枚举/MILP 证书，大规模存在稳定可复现的经典局部陷阱。

当前任一门槛都不满足，因此不应消耗硬件额度。

## 7. 不要做的事

- 不要用 EGFR、FA10、MK14 或 PPARG 的外层结果继续调旧 QUBO 权重、$k$ 阈值或接触描述符阈值。
- 不要因 PARP1、ESR2 或其他靶点结构数量不够而在事后降低 16 受体门槛。
- 不要把 `THRB` 当成 thyroid hormone receptor beta；历史 19 结构已明确无效于凝血酶。
- 不要在没有外部价值实例时运行更多量子硬件 PoC。
- 不要把本地临时验证目录、缓存、PID、外部数据库原始压缩包或 API token 提交到 Git。

## 9. 最终交接判断

这不是一个“什么也没有得到”的项目。它已经排除了多条会浪费大量对接和硬件预算的路线，并留下了一个可以被证伪、也有明确生物学解释的新问题：**能否在对接前识别功能互补构象，并仅在这些靶点上执行受约束组合优化？**

真正下一步是把这个问题在一个身份和结构门都干净的新靶点上完成预注册验证。若该验证仍失败，最有价值的结论是边界清晰的负结果；若通过，才有资格进入更大的构象池、严格经典难度测试和后续量子实现。
